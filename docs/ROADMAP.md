# ALICE roadmap

## Foundation — completed
- FastAPI API and static web UI
- Environment-based configuration
- OpenAI provider abstraction
- Persistent SQLite conversation memory
- Baseline RAG loading/chunking/retrieval
- Calculator and tool registry
- Permission boundary for external/IoT actions
- Bounded agent planner/executor
- Speech, vision, notification, web-search, and IoT extension boundaries
- Automated tests and GitHub Actions CI

## Next production upgrades
- Embedding-backed RAG and persistent vector index
- Streaming responses and cancellation
- Structured tool schemas and model-driven tool calling
- Authentication, rate limiting, audit logging, and secret management
- Observability and latency/token metrics
- Evaluation suite for answer quality and tool safety
- Production database abstraction
- Real speech/vision providers
- Controlled MSS gateway integration with deterministic safety logic
